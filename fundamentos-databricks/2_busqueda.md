# Introducción
Este recorrido guiado le muestra cómo utilizar la búsqueda para localizar elementos en todo el espacio de trabajo.

## Barra de búsqueda: parte superior de la página principal
La barra de búsqueda ofrece botones de búsqueda rápida para notebooks, tablas, trabajos, paneles de control o Mis activos. También muestra los activos con los que ha interactuado recientemente. No necesita saber el nombre exacto de un objeto, ya que también puede utilizar el lenguaje natural para buscar en función del contexto. Puede usar nombres exactos, nombres parciales o sentencias contextuales y el desplegable de búsqueda cambiará dinámicamente para mostrar posibles elementos que coinciden con su consulta. Utilice el tipo de objeto y el propietario para acotar la búsqueda.

## Página de resultados de búsqueda
Cuando presionas Enter al escribir en la barra de búsqueda, se te lleva a una página de resultados de búsqueda. Esta página proporciona una vista más amplia de los posibles resultados de su consulta. También puede filtrar sus resultados según criterios adicionales, como una lista ampliada de tipos de activos, activos de su propiedad específica o si el artículo está clasificado o no como Certificado. Los mosaicos de la página incluyen información sobre el activo para ayudarlo a limitar su búsqueda, incluido el propietario, la ubicación, cuándo se modificó el activo por última vez y etiquetas y detalles adicionales que pueden ser relevantes para ayudarlo a encontrar el elemento correcto. Al seleccionar un elemento, se abre en la misma ventana del navegador, pero puede usar Cmd + clic (Mac) o Ctrl + clic (Windows/Linux) para abrirlo en una nueva pestaña del navegador.

# Conclusión
En esta lección aprendiste cómo:
- Busque recursos con la barra de búsqueda en la parte superior de la interfaz de usuario de Workspace.
- Utilice la página de resultados de búsqueda para refinar su búsqueda viendo información adicional de activos.
- Aproveche los filtros en la página de resultados de búsqueda para limitar sus resultados según las diferentes características y calidades de los elementos de la plataforma.
- Ingrese una consulta utilizando lenguaje natural o términos de contexto para buscar utilizando información semántica en lugar de nombres exactos de activos.
